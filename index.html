AI-Powered Language Learning and Speaking Coach

My MCA final-year project. Learners practise French and Spanish out loud, the browser recognises their speech, and the app scores each answer against model answers with TF-IDF cosine similarity. The Gemini API adds feedback and group-discussion scoring, and a Chart.js dashboard tracks progress. Each language has 18 modules.

  • Flask
  • scikit-learn
  • Web Speech API
  • Gemini API
  • Chart.js
